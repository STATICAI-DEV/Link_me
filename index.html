STATIC CORE

The central execution and assistant engine behind StaticAI. STATIC CORE coordinates models, tools and workers; applies permissions and security policy; records durable state and logs; validates outcomes; and requires evidence before a task can be treated as complete. Models remain replaceable. The execution contract stays consistent.

Model-agnosticSwap local AI models without rebuilding the system.
Permission governedTools and workers act only through explicit allowed capabilities.
Deterministic executionReasoning can vary; execution follows controlled interfaces.
Evidence firstCompletion is verified rather than merely claimed.
